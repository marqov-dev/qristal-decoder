# Hardness literature for exact CTC decoding / MPS on memoryless λ-chains

Date: 2026-09-18. Scope: the forced-blank-separator subfamily of CTC = most probable output word of T independent slots with per-slot deletion (a "memoryless λ-chain" PFA; a product measure with deletions). All PDFs referenced below are saved under a local `pdfs/` directory (papers are not redistributed). "body-read" = I opened and read the relevant section; "abstract-only" = I saw only the abstract/preview/second-hand description.

## (a) Headline verdict

**OPEN — with materially higher confidence than before (≈0.9).** Every published hardness proof for "most probable string" (Casacuberta–de la Higuera 2000, Goodman 1998, Lyngsø–Pedersen 2001/02, Sun 2014) builds its gadget from a *nondeterministic branch into a family of position-indexed chains with a satisfied/unsatisfied (or vertex-identity) memory bit*; none is a single product measure, and none adapts trivially to one.
The deterministic-source, δ = 1/2 special case of our problem is *literally* the "most frequent subword" decision problem, which Fang (AofA 2024, arXiv:2406.02971) states in print is of unknown complexity ("we don't know whether there is a polynomial time algorithm … or to decide whether there is a subword that occurs at least a given number of times"); the two 2025–2026 follow-ups (Bukh–Saatashvili, Bruda, Tian) are extremal/enumerative and do not touch complexity.
No paper found gives either NP-hardness or a polynomial algorithm for the mode of a product-of-independent-slots-with-deletions distribution, under any of its names.

## (b) The target papers

### 1. Casacuberta & de la Higuera, "Computational complexity of problems on probabilistic grammars and transducers", ICGI 2000, LNAI 1891 pp. 15–24. DOI 10.1007/978-3-540-45257-7_2 — **OBTAINED, body-read (full author's version)**

Route. Springer paywalled (303 to IdP). Springer's official first-page preview service returned pp. 15–16 (`icgi2000-preview.pdf`). The full text came from the author's own homepage: the Wayback Machine capture (2017-08-09) of Colin de la Higuera's Nantes page hosts the submission version as `~cdlh/papers/icgi.stringmax.pdf` (saved as `casacuberta-delahiguera-icgi2000-author-version.pdf`, 9 pp., header "Submission to ICGI-2000"). A pirate mirror of the whole LNAI 1891 volume (nzdr.ru/kolxoz) surfaced in search; **not used**.

Problem definitions (verbatim, p. 2):
> "Problem Most Probable String (MPS). Instance A SRG G, and p ∈ Q⁺. Question Is there a string x ∈ Σ* with |x| ≤ |N|, such that pr_G(x) ≥ p ?"
> "Problem Restricted Most Probable String (RMPS). Instance A SRG G, d ∈ ℕ …, d ≤ |N|, and p ∈ Q⁺. Question Is there a string x ∈ Σ^d such that pr_G(x) ≥ p?"
> "RMPS is not just a special case of MPS. We will prove that both MPS and RMPS are NP-hard. As the probability of any string can be computed in polynomial time, both MPS and RMPS are in NP. We prove that MPS and RMPS are NP-hard by reduction from the 'Satisfiability' problem (SAT) [7]."

The reduction (verbatim, pp. 2–3). Given n variables v₁…vₙ and k clauses c₁…c_k:
> "• Σ = {f, t, $, #}
> • For 1 ≤ j ≤ k,
>   – A^j₀ ∈ N
>   – the rule S → $A^j₀ is in R with probability 1/k and rules B^jₙ → $ and A^jₙ → # are in R with an associated probability 1.
>   – for 1 ≤ i ≤ n with an associated probability 1/2:
>     ∗ A^j_i, B^j_i ∈ N
>     ∗ the rules B^j_{i−1} → tB^j_i and B^j_{i−1} → fB^j_i are in R.
>     ∗ if v_i appears as a positive literal in c_j then the rules A^j_{i−1} → fA^j_i and A^j_{i−1} → tB^j_i are in R.
>     ∗ if v_i appears as a negative literal in c_j then the rules A^j_{i−1} → tA^j_i and A^j_{i−1} → fB^j_i are in R.
>     ∗ if v_i does not appear in c_j then the rules A^j_{i−1} → tA^j_i and A^j_{i−1} → fA^j_i are in R.
>   Each of these rules have an associated probability of 1/2.
> • For RMPS fix d = n + 2."
> "Theorem 1: RMPS and MPS are NP-complete."
> "From the above construction, if the clause is satisfied for some solution (x₁,…,xₙ) the corresponding string $X₁…Xₙ$ (X_i is t if x_i is true, and X_i is f if x_i is false) will have probability 1/(k 2ⁿ) for each derivation linked to the clause. Note that the construction is in O(kn). The string length is n + 2 ≤ |N| = k·(2n+1). Fix p to 1/2ⁿ. Let m be a solution of SAT; … the corresponding $m$ is a string generated by G with k derivations all of probability 1/(k 2ⁿ); so the probability of $m$ by G is 1/2ⁿ. On the other hand, if the instance of SAT does not admit any solution, then as the only strings that have non null probability for the associated grammar are of length n + 2 (= d), and at least one clause is not satisfied (for example if the clause j is not satisfied, the corresponding derivation ends in A^jₙ), then no string has probability 1/2ⁿ."
Also (p. 4): "Theorem 2: MaxPS is APX-hard." (reduction from Max-SAT, same construction); and (p. 6) the transducer corollary "Theorem 3: MPT is NP-complete", with the remark "If the translation defined by E … is not ambiguous …, there is an efficient algorithm that computes an answer to the MPT problem in linear time."

What class of automaton the hard instance is. Acyclic, levelled (state = (clause j, position i, flag A/B)), 2k chains of length n+1 fed by a k-way nondeterministic branch S → $A^j₀; four terminal symbols; **no λ-transitions**; all strings have the same length n+2. The string probability is (1/k)·2⁻ⁿ·#{clauses satisfied by x}: a *mixture* of k clause-distributions, each of which is a chain with one bit of memory (A = "not yet satisfied", B = "satisfied"). Width per level = 2k states.

Does it reach our case? **No.** Our forced-blank subfamily is a levelled λ-PFA of width **one** (state = position only), whose string distribution is a single product measure with deletions. The gadget's entire leverage is (i) the initial k-way branch (mixture over clauses) and (ii) the A→B memory bit that makes "one derivation per satisfied clause" countable. Neither exists in a width-1 chain; Barrier Lemma (i) (private-symbol clause gadgets factorise) already rules out the obvious transplant. After λ-removal our chain is an acyclic PFA, so "NP-hard for acyclic PFA" is formally about a superclass; the hard instances have transition weights with no product structure across skipped positions, whereas ours have δ(q_t,a,q_{t'}) = (∏_{s=t+1}^{t'−1} r_s)·p_{t'}(a). Not covered, not trivially adaptable.

### 2. Casacuberta & de la Higuera, "Optimal linguistic decoding is a difficult computational problem", PRL 20(8):813–821, 1999. DOI 10.1016/S0167-8655(99)00045-8 — **NOT obtained (abstract-only)**

Routes tried: ScienceDirect (403 / bot page to curl and WebFetch), Semantic Scholar API (abstract elided by publisher; `openAccessPdf.status: CLOSED`), OpenAlex (`oa_status: closed`, no repository copy), Crossref (no abstract; references: Casacuberta IJPRAI 1996 growth transformations; Garey–Johnson; Jelinek 1997; Casacuberta PAMI 1992 "A comparative study of two search strategies for connected word recognition"; Rabiner–Juang 1993), CORE, CiteSeerX (dead/Wayback shell), HAL (no record), RiuNet/PRHLT (metadata only, no PDF), ResearchGate (403), Google Books API (429), author's archived Nantes page lists "Author's version → ../papers/PRL99.pdf" but the Wayback CDX has **no capture** of that file on any of the three historical hosts, and the live hosts are gone (404/refused).

What is known about it. Abstract (search-engine rendering of the ScienceDirect page; S2 tldr identical in substance): "The general problem of decoding an acoustic sequence into an optimal word string under the probabilistic framework cannot be solved by an algorithm in polynomial time … The main consequence of this result is that in the most successful framework of speech recognition only suboptimal decoding can be achieved." The ICGI 2000 paper (body-read) says nothing more specific than that its techniques were "developed for linguistic decoding"; de la Higuera–Oncina 2011 (body-read) say: "Casacuberta and de la Higuera (2000) proved the problem to be NP-hard, using techniques developed for linguistic decoding (Casacuberta and de la Higuera, 1999)" and "It can be shown (Casacuberta and de la Higuera, 1999; Vidal et al., 2005) that solving this problem consists in finding the most probable string inside the set of all acceptable translations, and this set is structured as a probabilistic finite automaton." Given the reference list (HMM speech decoding texts + Garey–Johnson) and the 2000 paper's self-description, the 1999 result is the same SAT gadget realised over an HMM/word-lattice decoding network; it cannot be a width-1 chain for the same reason. Confidence that the 1999 paper does not reach our case: high but second-hand.

### 3. de la Higuera & Oncina — three versions
- IWPT 2011, "Finding the most probable string and the consensus string: an algorithmic study", ACL W11-2904 — **obtained, body-read** (`W11-2904.pdf`). No hardness proof of its own; the key sentence: "The problem MPS is known to be NP-hard (Casacuberta and de la Higuera, 2000). In their proof the reduction is from SAT and uses only acyclic PFA." Also: "Goodman (1998) showed that, in the case of HMMs, the problem of finding whether the most most probable string of a given length n is at least p is NP-Complete … The problem was also addressed with motivations in bioinformatics by Lyngsø and Pedersen (2002). Their technique relies on reductions from maximal cliques." Positive side: BMPS solvable in O(b|Σ||Q|²/p); Section 4.4 has the exponential-length-MPS construction.
- FSMNLP 2013, "Computing the most probable string with a probabilistic finite state machine", ACL W13-1801 — **obtained, body-read** (`W13-1801.pdf`). Restricts to λ-free PFA ("this restriction is without loss of generality, as algorithms [Mohri, 2002, de la Higuera, 2010] exist allowing to transform, in polynomial time, more general PFA into PFA respecting the following definition"). Proposition 1: |w| ≤ (n+1)²/Pr_A(w); Algorithm 1 finds the consensus string with ≤ |Σ||A|²/p²_opt queue insertions (empirically ≲ 1/p²_opt). Exactly the c/p* regime of Graves' prefix search; no hardness content beyond "BMPS is known to be NP-hard [Casacuberta and de la Higuera, 2000]".
- J. Logic & Computation 24(2):311–330, 2014 ("2013" online), DOI 10.1093/logcom/exs049 — **not obtained**. HAL record hal-00838451 exists without a file; OUP paywalled; OpenAlex closed. Per the FSMNLP paper it "solved an associated decision problem … The condition required is that we are given an upper bound to the length of the most probable string and a lower bound to its probability" and "present[s] a construction proving that the most probable string can be of exponential length". Nothing suggests a new hardness reduction.

### 4. Goodman, "Parsing inside-out", PhD thesis 1998, arXiv cmp-lg/9805007, §3.6.1 — **obtained, body-read**
> "HMM Most Likely String (HMM-MLS) Instance: An HMM specification …, a length n in unary, and a probability p. Question: Is there some string of length n such that the specified HMM produces the string with probability at least p?" "Theorem 3.2 The HMM Most Likely String problem is NP-Complete."
Gadget (verbatim): "Create an HMM with 3f(f+v)+2 states … an equiprobable epsilon transition from the start state to the 3f states of the form [1,i,j] … The basic form of the network is START →ε [1,i,j] →(1,2,3) ··· [i,i,j] →j ··· [f,i,j] →(1,2,3) [f+1,i,j] →(T,F) ··· [f+k,i,j] →x(i,j) ··· [f+v,i,j] →(T,F) END". "This string will have probability 1/3^f × 1/2^{v−1} because there will be routes emitting that string through exactly f of the 3f subnetworks."
Class: a mixture (ε-branch) of 3f position-indexed chains, each deterministic at two positions and uniform elsewhere; no memory *within* a chain, but the mixture *is* the memory. Same structure as Casacuberta 2000 (which independently rediscovered it with a 2-bit flag instead of 3 branches per clause). **Does not reach our case**: a mixture of chains is not a product measure; Goodman even explains why a single-chain/one-section-per-clause attempt fails ("such a string may be output by multiple paths through the subnetworks corresponding to some of the clauses, and zero paths through … other clauses").

### 5. Lyngsø & Pedersen — ISAAC 2001 (LNCS 2223, pp. 416–428) / JCSS 65(3):545–569, 2002
Springer first-page preview of the ISAAC version obtained (`lp-isaac-preview.pdf`, pp. 416–417, body-read for those pages); JCSS body **not obtained** (ScienceDirect bot page; BRICS/CORE/RUA/homepages: nothing). Verbatim: "We show that computing the most likely string, and approximating its probability within any constant factor, is NP-hard … The hardness results hold even if we restrict the HMM to a model without silent states generating only strings over a binary alphabet." Reduction is from maximum clique (per IWPT 2011 and Sun 2014). Class: HMM whose hidden state encodes vertex identity — state memory, no silent states. Does not reach our case (our problem has silent/deletion moves and no state memory; their hardness is *stronger* on the silent-state axis but relies entirely on memory).

### 6. Brejová, Brown, Vinař (WABI 2004 preview obtained; JCSS 2007 not obtained) and Nánási–Vinař–Brejová arXiv:1210.2587 (body-read intro)
Different problem: most probable *labelling* of a *given* observed sequence ("Computing this most probable labeling was shown NP-hard by Lyngsø and Pedersen [9]. We improve this result by proving the problem NP-hard for a fixed HMM."). Their polynomial class is about HMM topology for decoding a given x; not about the most probable *output*. Does not reach.

### 7. Sun, "Exact decoding on latent variable conditional models is NP-hard", arXiv:1406.4682 — **body-read §III**
Max-clique reduction "Inspired by the consensus string problem on hidden Markov models [19]": latent variables H(E)={E¹…E^{|V|}}, H(N)={N¹…N^{|V|}}, edge scores encode adjacency — the latent variable carries vertex identity across positions (memory). Does not reach.

### 8. Vidal, Thollard, de la Higuera, Casacuberta, Carrasco, PAMI 2005 Parts I/II — **body-read** (author copies hosted on academic course pages, `pami-I.pdf`, `pami-II.pdf`)
Part I: "Proposition 8: The computation of the most probable string and the computation of the most probable constrained string in a PFA are NP-Hard problems. The formal proof of proposition 8 can be found in [43]. It should be noted that the problem is at least NP-complete but that the membership to NP is an open question." Part II §Conclusions: "we recall that the problem of deciding whether the probability of the most probable string is more than a given fraction is NP-hard. It is not known if the problem belongs to NP." No subclass results relevant to chains.

### 9. Bermúdez-Aguirre? — no: "Genetic algorithm for the weight maximization problem on weighted automata", GECCO 2020, arXiv:2004.06581 — body-read related work + appendix

## (c) The problem under other names

Correspondence used throughout: with a deterministic source x and i.i.d. deletion δ, P(l) = δ^{T−|l|}(1−δ)^{|l|}·emb(l,x); at δ = 1/2 this is 2^{−T}·emb(l,x), so **"most probable trace of x under a δ = 1/2 deletion channel" = "most frequent subsequence (subword) of x"**, a special case of our forced-blank subfamily (y[t][blank] = y[t][x_t] = 1/2).

- **Fang, "Maximal number of subword occurrences in a word", AofA 2024 / J. Exp. Math., arXiv:2406.02971 — body-read.** Explicit open-problem statements: "We are motivated by the following decision problem: given a word w and a number n, is there another word u that occurs at least n times as a subword in w? To our knowledge, it is unknown whether this natural problem in combinatorics of words can be solved in polynomial time." and Remark 4.2: "The main difficulty in the study of maximal subword occurrences is, in a sense, algorithmic. To the author's knowledge, we don't know whether there is a polynomial time algorithm to compute a most frequent subword of a given word, or to decide whether there is a subword that occurs at least a given number of times." Fang computed M₂(n) for n ≤ 40 by search. **This is the single most important external datum: the simplest instance of our problem is stated as open by a specialist in 2024.**
- **Bukh & Saatashvili, "Most frequent subsequences in a word", arXiv:2509.22619 (Sept 2025) — body-read.** Extremal: M_k(n) ≥ k^{n/4k(1+o(1))}, rate of convergence of μ_k. No algorithmic or complexity statement (grep for decision/polynomial/algorithm: nothing). Semantic Scholar lists no citations of it yet.
- Papers citing Fang (Semantic Scholar, 2026-09-18): Tian arXiv:2507.03205 "Counting occurrences of a pattern in a binary word" and Bruda arXiv:2607.02578 "Enumerating binary words restricted by subsequence frequency" — both enumerative; neither addresses the complexity of the maximisation (body-grep).
- **Elzinga, Rahmann, Wang, "Algorithms for subsequence combinatorics", TCS 409(3), 2008 — abstract-only**, plus Rahmann's project page (fetched): DP algorithms to count distinct subsequences, distinct common subsequences, and matching/joint embeddings of a *given* pattern. The page "does not mention finding the most frequent subsequence". So counting emb(l,x) for fixed l is polynomial (which we knew); the argmax is not treated.
- **Weighted/uncertain strings (PWMs)**: Amir–Gotthilf–Shalom "Weighted LCS" (JDA 2010), Kipouridis–Tsichlas arXiv:1901.04068 (body-read defs), Charalampopoulos et al. "Weighted SCS revisited" arXiv:1909.11433 (body-read defs), Cygan et al. CPM 2011. All NP-hardness there is for a **max-over-embeddings** semantics — verbatim: "SUBS(X,a) = {s ∈ Σ* | ∃π … such that P_X(π,s) ≥ a}" and "We say that a (standard) string S matches a weighted string W with probability at least 1/z … if P(S,W) ≥ 1/z"; hardness comes from Subset-Product/Subset-Sum on the log-probabilities of a *single chosen* embedding. Our objective sums over embeddings; the gadgets do not transfer (a sum over exponentially many embeddings cannot be pinned to one subset-product witness). Closest cousin, not the same problem.
- **Deletion channel / trace reconstruction**: searches for "most likely trace", "mode of the deletion channel output", "maximum likelihood trace" return only (i) sample-complexity trace reconstruction (Holenstein et al., Chase, Nazarov–Peres — not opened, not computational), (ii) ML *decoding* of a codeword from traces (input given outputs — a different direction, involving common-supersequence counting), and (iii) survey remarks (Mitzenmacher) that decoding requires counting embeddings. Nothing on the mode of the output distribution.
- **String-kernel pre-image** (Giguère et al. arXiv:1412.1463, ICML 2015 — abstract/snippet only): argmax over strings of a gap-weighted subsequence-kernel score is "conjectured to be NP-Hard" for the *normalised* GS kernel; no theorem. Same flavour (sum over embeddings with per-gap weights), still open there too.
- **Frequent-pattern mining** (Yang KDD 2004; Iwanuma et al. 2005): "frequent subsequence" there means support over a database of sequences (or window counts), #P/NP results are about maximal-pattern enumeration — different semantics.
- **"ε-PFA / λ-PFA / chain / acyclic / deterministic-with-λ" MPS**: no paper found giving a result for width-1 (position-only) chains; the only acyclic-specific statements are the Casacuberta 2000 and Lyngsø–Pedersen hardness for *general* acyclic/levelled automata with memory, and de la Higuera–Oncina's remark that λ-removal is polynomial (so the λ-chain is an acyclic PFA — a superclass statement, not a subclass one).
- **CTC-specific**: no paper claims NP-hardness (or tractability) of exact CTC decoding; all CTC sources say only that naive enumeration is exponential and use beam/prefix search. Graves' "no efficient algorithm known" stance is not contradicted anywhere I could find.

## (d) What to do next

1. Treat the verdict as OPEN and cite Fang 2024 (Remark 4.2 + intro) as the external witness that even the deterministic-source, δ = 1/2 subcase is unresolved; cite Casacuberta–de la Higuera 2000 (author's version, gadget quoted above), Goodman 1998 §3.6.1 and Lyngsø–Pedersen 2001 as the three closest hardness results, each blocked by the same feature (a mixture/memory bit the product measure lacks).
2. If a proof attempt is made in either direction, the right intermediate object is the **levelled PFA of width w** (state = (position, one of w flags)): Casacuberta's gadget is width 2k, Goodman's width 3f; our case is width 1. A hardness proof for fixed width ≥ 2 (or a poly algorithm for width 1) would be new; the existing gadgets need width growing with the instance.
3. Two cheap experiments to sharpen intuition before theory: (i) brute-force the most-frequent-subword problem to n ≈ 40 (Fang's regime) and test whether the argmax is always found by prefix search with a small expansion budget; (ii) check whether the Elzinga–Rahmann–Wang embedding-count DP supports a monotone upper bound tight enough for branch-and-bound (this is what de la Higuera–Oncina's PP(w) bound does for general PFA).
4. Still worth obtaining if convenient: the 1999 PRL paper (author's version was once at `pagesperso.lina.univ-nantes.fr/~cdlh/papers/PRL99.pdf`; e-mailing the author is the remaining legitimate route) and the JLC 2014 version — but nothing in the record suggests either contains a different reduction.
