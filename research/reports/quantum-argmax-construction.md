## (a) Headline

1. **C7 works.** The algorithm is correct and provably Õ(1/√p*): 272/272 tables return a label with p = p* (0 failures, gate PASS), expected rounds ≤ 1 + ln(1/p*) (new weighted rank lemma, proved below and matched numerically), expected search cost ≤ 9/√p* Grover iterations, and — a property QB's design lacks — **termination is self-certifying**: at threshold θ any surviving label has mass > θ, so the empty-set test costs a known O(1/√θ).
2. **In equal units the speedup at the 5 dB point is ≈ 1.9× (range 1.2–4×) at a cost of ~5×10¹⁵ coherent Toffolis and ~1.7×10⁵ logical qubits; 10 dB dies (1.6×10⁻⁴×); 0 dB reaches ~900× but needs ~9×10¹⁸ Toffolis** against a classical job that finishes in hours at exascale. The crossover is p* ≲ 2×10⁻¹¹ (D=40) and the speedup grows only as √(p*_x/p*). There is no practical advantage; the ~10⁴–10⁵× gap to earlier programme figures is entirely the W factor, the certification constant, uncomputation and the 57–80-bit registers the 1.02–1.12 margins force.
3. **Not novel as a primitive.** The construction *is* van Apeldoorn–Gilyén–Gribling–de Wolf's "Generalized Minimum-Finding" (arXiv:1705.01843, Appendix C, Theorem 49; body read): given U|0⟩ = Σ_k |ψ_k⟩|x_k⟩, the minimum is found with O(1/√Pr(X ≤ x_min)) uses of U, U⁻¹, constant "something like C ≈ 25". My weighted rank lemma is their Lemma 47 verbatim and my telescoping bound is their eq. (30). What is new here: the CTC instantiation (U = product Born state ∘ reversible collapse; the exact forward-recursion comparator as the threshold oracle), the self-certifying cap (marked mass ≥ θ, so termination needs no prior bound on p* and yields an explicit certificate, which Algorithm 3 lacks), the E[rounds] ≤ ln(1/p*) corollary, the margin→bits analysis, and the equal-units costing. Belovs' Ω(1/d_H) (arXiv:1904.02192, Thm 4, body read) applies to the black-box version of our U and gives Ω(1/(√p*(1 − 1/√m))) for mode certification — consistent with the white-box evaluator being the thing that removes the margin factor from the query count and moves it into the register width. Paper-worthy only as (i) a minimal correct quantum CTC decoder built from QB's own components, plus (ii) a resource-level no-go.

## (b) The algorithm, precisely

**Registers.** P: path register, T qudits of dimension W (⌈log₂W⌉ qubits each). L: label register, D_max symbols of ⌈log₂(W−1)⌉ qubits + a length field (encoded here as an index into the reachable label set). R: fixed-point value register, b bits, plus the forward-recursion workspace (T·S·b qubits naively, S = 2D_max+1; 2√T·S·b with two-level checkpointing). F: one flag qubit.

**State preparation A** (uses no measurement; A⁻¹ is A reversed):
- U_prod = ⊗_t R_t, R_t|0⟩ = Σ_s √y[t][s] |s⟩ (one W-dimensional rotation per frame). Because the path measure is a product measure, U_prod|0⟩ = Σ_π √p(π|y)|π⟩ exactly.
- B: the reversible collapsing map |π⟩|j⟩ → |π⟩|j ⊕ B(π)⟩ (QB's `decoder_kernel.cpp:173–280`, previously verified on 200 tables; here built as an explicit permutation and asserted bijective).
- A|0⟩ = |Ψ⟩ = Σ_π √p(π) |π⟩|B(π)⟩ = Σ_l √p_l |l⟩ ⊗ |φ_l⟩, with |φ_l⟩ the normalised conditional path state. Measuring L gives l w.p. p(l|y) (the Born rule sums the preimage). Gate: worst |marginal − p(l|y)| = 8.9e-16 over 248,232 labellings.

**Oracle O_θ.** On |l⟩, run the CTC forward recursion (Graves 2006 §4.1; `ctc.py:ctc_forward`) reversibly: α_t(s) = (α_{t−1}(s) + α_{t−1}(s−1) + [ext_s ≠ blank, ext_s ≠ ext_{s−2}] α_{t−1}(s−2)) · y[t][ext_s], s over the 2|l|+1 extended states, y[t][ext_s] fetched by a W-way select on the quantum symbol; output p̃_l = α_T(S−1)+α_T(S−2) into R; compare with the classical constant θ; flip F if p̃_l > θ; uncompute R and the workspace. O_θ is a diagonal phase on L only — its action is fully determined by the function l ↦ p̃_l, which is why the simulation may legitimately implement it as that diagonal.

**Amplitude amplification.** Q_θ = −A S_0 A⁻¹ S_θ = (2|Ψ⟩⟨Ψ| − I) S_θ (BHMT eq. 1–2). Good subspace = span{|π⟩|l⟩ : p_l > θ}; initial success probability a(θ) = M(θ) = Σ_{p_l>θ} p_l. Since Q preserves span{|Ψ_0⟩,|Ψ_1⟩} (BHMT Lemma 1), the conditional distribution of the measured label *given good* is exactly the conditional of |Ψ⟩: l w.p. p_l / M(θ). This is the weighted sampling everything below rests on.

**Search primitive: capped QSearch** (BHMT Thm 3, c = 1.5). l ← 0; loop: l++, M = ⌈c^l⌉; measure A|0⟩, stop if good; pick j ∈ [1,M] uniformly, measure Q^j A|0⟩, stop if good. **Cap:** once M ≥ M_cap := ⌈κ/√θ⌉ (κ = 2) hold M = M_cap and declare "empty" after K = 12 failed loops. Justification: if the marked set is non-empty then a ≥ θ, so M_cap ≥ 2/√a = M_0 of BHMT's proof with c_0 = 1/4, and each capped loop succeeds w.p. ≥ ½(1−c_0) = 3/8 (their eq. 9); P[false "empty"] ≤ (5/8)^K = 3.5×10⁻³. No round can run forever — unlike Dürr–Høyer's step 2, which needs an external time-out because with a uniform start the marked mass t/N is not lower-bounded by the threshold.

**Dürr–Høyer loop.** θ ← p_{l₀} with l₀ a Born sample of |Ψ⟩ (the analogue of DH's "choose threshold index uniformly at random"). Repeat: (l, ·) ← cappedQSearch(θ); if empty, stop and return the current label; else θ ← p_l. The last capped QSearch is the certification: with confidence ≥ 1 − (5/8)^K no label has p̃ > p̃_{returned}.

Ties: exact ties above the returned value cannot exist (the certificate says so); ties *at* it are never marked; the algorithm returns some argmax, which is all "argmax" can mean.

## (c) Correctness and expected cost, with citations

**The primitive is Theorem 49 of van Apeldoorn, Gilyén, Gribling, de Wolf, arXiv:1705.01843 (Appendix C, body read).** Their Meta-Algorithm 2 ("Sample a value s_t according to the conditional distribution Pr(X = s_t | X < s_{t−1})"), Algorithm 3 ("Use the exponential search algorithm with amplitude amplification on states such that x_k < s_{t−1} to obtain a sample |ψ_k⟩|x_k⟩"), Lemma 47 (Pr(x_k ∈ S(X)) = Pr(X = x_k)/Pr(X ≤ x_k)), Lemma 48 ("the expected number of uses of U and U⁻¹ before obtaining a sample x ≤ x_k is at most C/√Pr(X ≤ x_k)", with eq. (30): Σ_{ℓ>k} [Pr(X = x_ℓ)/Pr(X ≤ x_ℓ)]·(1/√Pr(X < x_ℓ)) ≤ 2/√Pr(X ≤ x_k)), and Theorem 49 ("If we run Algorithm 3 with input satisfying M ≥ 4C/√Pr(X ≤ x) … then at termination we obtain an x_i from the range of X that satisfies x_i ≤ x with probability at least 3/4 … It is not too hard to work out the constant by following the proof of [BBHT98] providing something like C ≈ 25"). They state explicitly that it "generalizes the results of Dürr and Høyer [DH96] in a manner similar to the way amplitude amplification [BHMT02] generalizes Grover search". C7 is Theorem 49 applied to X = −p(l|y) with U = B ∘ U_prod and the comparator implemented by the exact forward recursion. The derivations below are kept because they carry the explicit constants I use (9 + 12 rather than 4C = 100) and because the weighted lemma is what the CTC simulation tests; they are not claimed as new.

**Sources read in full:** BHMT, arXiv:quant-ph/0005055 (Thm 2: "if we compute Q^m A|0⟩ and measure the system, the outcome is good with probability at least max(1−a, a)" with m = ⌊π/4θ_a⌋; Thm 3: "Algorithm QSearch finds a good solution using an expected number of applications of A and A⁻¹ which are in Θ(1/√a) if a > 0, and otherwise runs forever"; their proof sketch, eq. 9: for 0 < a < 3/4 and any M the success probability in step 7 is ≥ ½(1 − 1/(2M√a)); Thm 4 gives certainty when a is known). Dürr–Høyer, arXiv:quant-ph/9607014 (Lemma 1: "p(t,r) = 1/r if r ≤ t", proved by induction on t using "the output distribution of the exponential searching algorithm is uniform"; Lemma 2: expected total time ≤ (45/4)√N + (7/10)lg²N, using BBHT's "at most (9/2)√(N/t)" expected iterations per search; "If the values in T are not distinct … p(t,r) = 1/r now becomes an inequality, p(t,r) ≤ 1/r").

**Correctness.** Every accepted label satisfies p̃ > θ_current, so thresholds strictly increase and the loop ends after finitely many rounds; the final capped QSearch certifies emptiness with error ≤ (5/8)^K. Hence the output is argmax_l p̃_l with probability ≥ 1 − (5/8)^K, where p̃ is the (exactly reproducible) b-bit oracle function; p̃-argmax = p-argmax whenever p* − p₂ > 2ε with ε the oracle's absolute error (see failure mode 1).

**Weighted rank lemma (= vAGGdW Lemma 47; replaces DH Lemma 1).** Sort labels p₁ ≥ p₂ ≥ … and let P_r = p₁+…+p_r. Let q(t,r) be the probability that label r is ever a threshold when the current marked set is {1..t}. With weighted sampling, q(r,r) = p_r/P_r and
q(t+1, r) = p_r/P_{t+1} + Σ_{k=r+1}^{t+1} (p_k/P_{t+1}) q(k−1, r) = (p_r/P_{t+1})[1 + (P_{t+1} − P_r)/P_r] = p_r/P_r,
independent of t — exactly DH's induction with 1/r replaced by p_r/P_r (uniform p recovers 1/r). With ties it becomes ≤, as in DH.

**Expected rounds.** E[#thresholds ever chosen, incl. the initial sample] = Σ_r p_r/P_r ≤ 1 + Σ_{r≥2} ln(P_r/P_{r−1}) = 1 + ln(1/p*), using x/P ≤ ln(P/(P−x)). So **E[rounds] ≤ ln(1/p*)** ≈ 26 at 5 dB, 40 at 0 dB. (DH's uniform bound ln N would be ln(#labels) — far larger and not even well defined here.)

**Expected search cost.** A round whose threshold is label r has marked mass P_{r−1} and costs ≤ (9/2)/√P_{r−1} Grover iterations in expectation (BBHT constant as used by DH). Total ≤ Σ_{r≥2} (p_r/P_r)(9/2)/√P_{r−1}. Each term ≤ (9/2)·∫_{P_{r−1}}^{P_r} x^{−3/2}dx (the ratio is (1+√u)/2 ≤ 1 with u = P_{r−1}/P_r), so the sum telescopes: **E[G_search] ≤ 9/√p* − 9** (this is vAGGdW eq. (30) with the BBHT constant made explicit; they prove the same 2/√p₀ by a subdivision argument). Gate: worst Σ_r (p_r/P_r)/√P_{r−1} · √p* over 272 tables = 1.756 ≤ 2, PASS. The geometric sum is dominated by the last rounds, as the brief anticipated.

**What C7 adds to Theorem 49.** Algorithm 3 stops on a *budget* M ≥ 4C/√Pr(X ≤ x) and succeeds w.p. 3/4 by Markov — it needs a prior lower bound on p* and returns no certificate. In C7 the threshold itself lower-bounds the marked mass (M(θ) ≥ θ whenever non-empty), so every round is capped at ⌈2/√θ⌉ without knowing p*, the loop terminates on an explicit emptiness test, and the only failure mode is the certificate's (5/8)^K. The E[rounds] ≤ ln(1/p*) corollary is immediate from their Lemma 47 but not stated by them.

**Certification cost.** K loops at M_cap with E[j] = (M_cap+1)/2: **G_detect ≈ K(κ/√p* + 1)/2 = 12/√p* + 6** at K = 12, κ = 2. This *exceeds* the expected search cost; a search lower bound (BBHT) says Ω(1/√θ) queries are necessary to rule out a marked mass ≥ θ, so only the constant is improvable (amplitude estimation distinguishing a = 0 from a ≥ θ, or a smaller K at higher δ). Total expected Grover iterations ≈ **21/√p*** with each iteration = O_θ + A⁻¹ + A. Failure probability: 3.5×10⁻³ from the certificate; the search itself has no failure mode (it only stops on verified good outcomes).

**Lower bound (Belovs, arXiv:1904.02192, body read).** His model (iv) — an oracle preparing Σ_a √p_a |a⟩|ψ_a⟩ "where ψ_a are arbitrary unit vectors" — is exactly our U|0⟩ = Σ_l √p_l |l⟩|φ_l⟩. Theorem 4: "For any two probability distributions p and q on the same space A, and any model of accessing them from Section 3, the quantum query complexity of distinguishing p and q is Θ(1/d_H(p,q))." A mode-finder must distinguish p from q = p with the top two probabilities swapped, for which d_H² = 1 − Σ√(p_a q_a) = p*(1 − 1/√m)², so in the black-box model any algorithm needs **Ω(1/(√p*·(1 − 1/√m)))** uses of U — 18× more than 1/√p* at m = 1.12 and 101× at m = 1.02. C7 evades the margin factor only because O_θ is a *white-box* exact evaluator of p(l|y) (the black-box model cannot compute p_l from U alone); the margin then reappears as register width, b ∝ log(1/(1 − 1/m)), i.e. logarithmically rather than multiplicatively. The same bound says any sample-only route — including coherent amplitude thresholding with a relative ambiguity band Δ (Guo et al., arXiv:2606.06316, abstract only; the quantum-literature-sweep report records a QSVT Heaviside at O(1/√Δ) per application, proven optimal) — must pay the margin multiplicatively: with Δ ≈ m − 1 that route costs O(1/(√Δ·√p*)) per DH pass and, per that reading, O(1/p*) overall, i.e. no better than classical; the exact-evaluator route is the right one. Belovs' bound is a black-box statement and says nothing about quantum vs classical for CTC, where the classical prefix search is also white-box.

**Hidden failure modes.**
1. *Precision vs margin.* The forward recursion is a product of column-substochastic linear maps (column sums of D_t·A are y(blank)+y(l_k)+y(l_{k+1}) ≤ 1 or y(blank)+y(l_k) ≤ 1), so per-cell rounding errors 2^{−b} add without amplification: |p̃_l − p_l| ≤ T·S·2^{−b}. Need this < (p* − p₂)/2 = p*(1 − 1/m)/2 ⇒ **b ≥ log₂(2TS / (p*(1−1/m)))**: 5 dB (T=300, D=40, p*=5e-12, m=1.12) → **b = 57**; 0 dB (6e-18, 1.02) → **b = 79**; 10 dB (1.2e-2, 1.25) → **b = 25**. Rescaling the table rows by classical constants changes every p_l by the same factor and does not help: the register must span the dynamic range from p* up to the intermediate α's (≤ 1); per-frame scaling by 1/max_s y_t(s) makes intermediates as large as 1/∏max y ≈ 10²³. Floating point (Haener et al., arXiv:1807.02023, Table 2: 64-bit multiplier 122,752 T = 17,536 Toffoli-equivalents vs 11,683 for my 57-bit fixed-point cell) is more expensive, not less. Simulation: with a b-bit-rounded oracle the algorithm always returns an argmax of p̃ and is never wrong when p* − p₂ > 2^{−b} (0/1,298 across b = 3…12), while it returns the runner-up in 66/111 ambiguous cases at b = 3, falling to 4/13 at b = 12 — the failure is exactly the predicted one.
2. *Ties.* Handled above; near-ties within 2ε are indistinguishable by construction and the certificate is then "no label beats the output by more than 2ε".
3. *Certification dominates* (12/√p* vs ≤ 9/√p* search); the classical algorithm certifies for free (its termination condition is the certificate).
4. *Workspace.* T·S·b qubits for the naive reversible DP (1.4×10⁶ at 5 dB); two-level checkpointing gives 2√T·S·b ≈ 1.7×10⁵ at ~3× instead of 2× time. Either way this dwarfs the search registers.
5. *Variable |l|.* The oracle circuit must be laid out for S_max = 2D_max+1 and pad shorter labels with dead states; cost scales with D_max, not |l|.
6. *Symbol fetch.* y[t][ext_s] indexed by a quantum symbol is a W-way select of a classical constant (≈ W·b Toffolis); it is not QRAM over the label space, but it is a real cost (16% of the cell at 5 dB).

## (e) Equal-units cost model (`../code/quantum-argmax-construction/c7_cost.py`, output `c7_cost.out`)

Unit: one b-bit fixed-point multiply-add = one Toffoli-equivalent (generous to quantum; an FT Toffoli costs far more than a FLOP).

*Classical (Graves 2006 §3.2 = `ctc.py:topk_labellings`, exact with a large beam; N57):* each expansion of the best prefix scores all W−1 children incrementally, each child O(T) with 2–3 multiply-adds per frame (the (p_b, p_nb) update); expansions ≈ |T_{p*}| ≈ c/p*, c = 1.8 (N30). **Cost_C = 3·c·(W−1)·T/p***, W = 32 (wav2vec2 vocabulary). N60's "×T×4 FLOP per node" omitted the W−1 children; I include it (it favours quantum by 31×) and give the node-only figure alongside. With 2 instead of 3 multiply-adds per frame all speedups below shrink by 1.5×.

*Quantum:* **Cost_Q = G · [2·T·S·C_cell(b) + T(W + 4⌈log₂W⌉)]**, G = 21/√p* (9 search + 12 certificate), S = 2D+1, uncompute factor 2, C_cell = (3b² − 2) + 2b + W·b: multiplier from Muñoz-Coreas & Thapliyal arXiv:1706.05113 Table IV, T-count 21n² − 14 ⇒ 3n² − 2 Toffoli-equivalents at 7 T/Toffoli; two Gidney adders (arXiv:1709.06648, "4n + O(1)" T ⇒ n Toffoli-equivalents); one W-way symbol select. b from the margin analysis above.

**Crossover.** T cancels. Cost_Q ≤ Cost_C ⇔ **p* ≤ p*_x = [3c(W−1) / (2·21·S·C_cell(b))]²**, b solved self-consistently: D = 20 / 40 / 60 → p*_x = 1.0e-10 / 2.0e-11 / 8.0e-12 (margin 1.12; 1.02 and 1.25 move it by < 25%). Speedup = √(p*_x/p*): every extra 100× of speedup costs 10⁴× in p*.

**Check of the literature sweep's per-U estimate (quantum-literature-sweep report §2).** The rough Õ(T·(W+D)) arithmetic per U with gate p* < (c/(W+D))² ≈ 6×10⁻⁴ is wrong in structure and by ~10⁷ in value: the symbol fetch y[t][l_k] is needed for every (frame, label position) cell, so it multiplies rather than adds — per oracle **T·S·(3b² + 2b + W·b)** with S = 2D+1, i.e. Õ(T·D·(b² + W·b)), and the b² term dominates at b = 57 (9,747 vs 1,824 for the W·b select). Correct units-equalised gate: p* ≲ [3c(W−1) / (42·S·C_cell(b))]² = 2×10⁻¹¹ at D = 40. A multiplexed constant-multiplier could shave the b² constant (shift-and-add against a classical constant costs ≈ b²/2 per symbol, but it must be selected among W symbols), not the scaling.

**Verdict in plain terms.** At 5 dB the honest equal-units speedup is ~2× (0.06× if the classical side is charged per node as N60 did), for 5×10¹⁵ coherent Toffolis and 1.7×10⁵ logical qubits; at a logical Toffoli rate of 1 MHz that is ~170 years of wall clock against ~10 s of classical time at 1 PFLOP/s. At 0 dB the ~900× is real in equal units but the absolute cost (9×10¹⁸ Toffolis, ~6 orders beyond any published fault-tolerant estimate) is against a classical computation of a few hours at exascale. The 79-bit registers are forced by the 1.02 margin — the very margins that make certification the only reason to want the exact mode. C7 removes QB's AE/QPE/nesting/QRAM and F11's √D and polylogs (N58's ≈3×10³–6×10³), and the result is still no advantage; the prior 8×10⁴×/10⁸× figures (N49) and even N58's 8.9× at 5 dB were unit mismatches and constant-dropping, as suspected.

## (f) Novelty check

**Primitive: already published.** van Apeldoorn, Gilyén, Gribling, de Wolf, arXiv:1705.01843, Appendix C, Theorem 49 "Generalized Minimum-Finding" (body read; quotes in §c) is weighted-start amplitude amplification with threshold raising over an implicitly prepared distribution, with cost O(1/√Pr(X ≤ x_min)) and C ≈ 25. C7 is that theorem instantiated. A parallel check (the citation-check report) verifies its proof and constant on synthetic distributions; the CTC simulation here is the complementary check (0/272 failures, cost-sum ≤ 2/√p* PASS).

Searched (WebSearch, 2026-09-18): quantum mode finding / most likely outcome; heavy hitters; most probable string; MAP decoding + amplitude amplification; quantum Viterbi; quantum MAP inference Grover; Hamoudi–Magniez; Montanaro Monte Carlo; argmax from qsample/purified-query access; Grover adaptive search decoding. What was **not found**: the CTC instantiation (product Born state ∘ reversible collapse ∘ exact forward-recursion comparator), the marked-mass-≥-θ self-certifying cap, and any equal-units costing against prefix search. Closest three applications after Theorem 49:

1. **Low, Yoder, Chuang, "Quantum inference on Bayesian networks", arXiv:1402.7359** (abstract read; body not). "Performing exact inference on Bayesian networks is known to be #P-hard. Typically approximate inference techniques are used instead to sample from the distribution on query variables given the values e of evidence variables." Quantum rejection sampling with amplitude amplification from the q-sample gives O(n2^m P(e)^{−1/2}) per sample. Same primitive (AA on a Born-rule start state of a graphical model), but the target is *sampling*, and "the abstract does not mention MAP, most probable explanation, argmax, or mode". C7 is what you get by pointing that primitive at the mode via DH.
2. **Dürr & Høyer, arXiv:quant-ph/9607014** (body read) and its decoding descendants, e.g. **"Quantum Speedup for Polar Maximum Likelihood Decoding", arXiv:2411.04727** (abstract only): "we propose a novel ML decoding architecture for polar codes based on the Grover adaptive search, a quantum exhaustive search algorithm … a pure quadratic speedup in query complexity." Threshold-raising minimum finding, but over a *uniform* superposition of codewords — the same structure as QB's decoder and the same √(#candidates) cost; no weighted start, no preimage sums. Likewise **"Quantum Algorithms for Structured Prediction", arXiv:1809.04091** (abstract only): "a stochastic gradient descent that uses the quantum minimum finding algorithm … scales with the square root of the size of the label space".
3. **"Quantum enhanced rare event discovery and sampling", arXiv:2606.06316** (abstract only): "Efficiently discovering and sampling events with probability below a threshold is therefore of critical interest … the rare events are not known in advance, they cannot be flagged for amplification using standard techniques … The algorithm achieves the optimal quantum scaling with the rarity threshold" (Õ(1/√p_rare) per the search summary). Mechanically the mirror image of C7: threshold-marking on a sampler's Born-rule state, but for events *below* a threshold; it must be read in full to see whether its threshold oracle is a coherent evaluation of p(x) as here. Related: **SQD-AA, arXiv:2605.02565** (abstract only): "uses AA to sequentially reduce probabilities of already measured bitstrings" — AA from a sampler state with data-dependent marking, not mode finding.

Already on file (earlier internal claims ledger, N65): Bausch et al. 2021 do *best-path* (no collapsing map). Caveat: the weighted rank lemma may exist in the Grover-adaptive-search/global-optimisation literature (Bulger–Baritompa–Wood) under another name; I did not find it and did not read those bodies.

## (g) What would make this a paper, and the single next experiment

A paper here is *not* "quantum speedup for CTC decoding", and it is not "a new minimum-finding primitive" either — that is vAGGdW Theorem 49. What is defensible: (1) the minimal correct quantum CTC decoder — product-state amplitude encoding + QB's coherent B + Theorem 49 with an exact forward-recursion comparator — with the self-certifying cap (M(θ) ≥ θ) and the E[rounds] ≤ ln(1/p*) corollary, a full end-to-end verification, and the Belovs-bound explanation of why the white-box evaluator is necessary (any sample-only route pays 1/(1 − 1/√m)); (2) the equal-units resource statement showing the crossover p* ≲ 10⁻¹¹ and 10¹⁵–10¹⁹ Toffolis at the only operating points where exact decoding differs from beam search — a resource no-go for this construction. This must engage Novosad 2026 (N144, still abstract-only): if the oracle gap is linguistic, even a free exact decoder buys nothing, and the paper's framing becomes purely "a correct algorithm and its cost".
